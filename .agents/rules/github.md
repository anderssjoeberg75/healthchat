# Automatisk uppladdning till GitHub

När ändringar har gjorts, testats och verifierats i projektet:
1. Gör alltid `git status` för att kontrollera alla ändrade och nya filer.
2. Lägg till alla relevanta källkodsfiler med `git add .`.
3. Skapa en tydlig commit med `git commit -m "<beskrivning>"`.
4. Pusha alltid ändringarna till GitHub med `git push origin main`.
